Final Takeaways and Next Steps

Findings
This project has two primary conclusions. One: Music has changed over the last century> We observed measurable changes in a number of the music characteristics such as acousticness and instrumentallness. Whereas, other such as energy and danceability have increased. Further, we found that these changes have been tied to world events, with more somber music tied to the Great Depression and Recession.

Additionally, we found that the relation between different musical qualities and popularity varies. Meaning, while there are some attributes like acousticness that have a clear relationship with popularity, there are a number of others that have no relationship at all.

Future studies
  • instead of using the spotify API's value of 'popularity' which measures current popularity, this data could be used in conjunction with billboard positions, record sales, etc. to measure the popularity of these songs on their release, rather than today.
  • Creating a regression to quantify the relationship between different attributes and a songs popularity. If successful, this could be a tool that could predict how popular a song should be based on different characteristics.
